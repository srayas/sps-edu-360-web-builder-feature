# SPS EDU 360 — Web Builder

A visual app builder on Angular 22 + Angular Material 3: drag-and-drop pages, forms with validation, data tables with editable cells, dialogs and notifications, reactive logic, functions and workflows — and pages generated by any AI assistant from a screenshot or Figma design.

| Path | What |
| --- | --- |
| `apps/web-builder` | The studio and the app renderer (Angular) |
| `api/web-builder-service` | Optional NestJS service: stores projects, publishes apps, collection records |
| `packages/shared-ui`, `packages/json-logic` | Shared Material UI pieces and the JSON Logic engine |
| `docs/ai` | Prompt, JSON schema and examples for designing pages with AI ([guide](docs/ai/README.md)) |

## Run locally

Requirements: **Node.js 24** (or 22.22.3+; Angular 22 refuses older versions) and **pnpm 9+**.

```bash
git clone https://github.com/srayas/sps-edu-360-web-builder-feature.git
cd sps-edu-360-web-builder-feature
git checkout feature/angular-material-builder

nvm use              # picks Node 24 from .nvmrc (or install Node 24 another way)
corepack enable      # provides pnpm
pnpm install

pnpm dev:builder     # studio at http://localhost:3002
```

Projects are stored in the browser by default, so the studio works without the service.

### Optional: the service (server storage, publishing, shared collections)

```bash
cp api/web-builder-service/.env.example api/web-builder-service/.env   # PORT=3000
pnpm --filter @spsedu360/web-builder-service start:dev                  # http://localhost:3000 (Swagger at /swagger)
```

Then set `apiBaseUrl: 'http://localhost:3000'` in `apps/web-builder/src/environments/environment.ts` and restart `pnpm dev:builder`.

### Useful commands

```bash
pnpm --filter @spsedu360/web-builder test         # unit tests (model, logic, runtime)
pnpm --filter @spsedu360/web-builder build        # production build → apps/web-builder/dist
pnpm --filter @spsedu360/web-builder ai:docs      # regenerate docs/ai from the block registry
pnpm --filter @spsedu360/web-builder spec:check docs/ai/examples/team-dashboard.page.json
pnpm validate                                      # prettier + tsc + lint (also runs on commit)
```

## Designing with AI

Click **✨ Import from AI / JSON** in the studio, copy the AI prompt into ChatGPT / Claude / Gemini / Copilot, attach a screenshot or Figma link, and paste the JSON reply back — the page renders on the canvas. Details: [docs/ai/README.md](docs/ai/README.md).
